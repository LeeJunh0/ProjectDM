# 버섯·갑옷 공격 애니메이션 시안

2026-11-04. 게임 적용 전 검토용이며 런타임 리소스·공격 판정을 변경하지 않는다.

- `index.html`: 생성한 6프레임씩을 반복 재생한다. 일시정지·재생 속도·이펙트 표시를 조절할 수 있다.
- `attack-sheet.png`: 버섯(위)·갑옷(아래), 각 6프레임. 2172×724, 투명 배경.
- 버섯은 기존 빨간 갓과 크림색 몸을 참고한다. 움츠리기·부풀리기·발사·반동·복귀 순서다. 미리보기의 별도 포자는 느린 직선 이동과 1.2초 수명을 사용한다.
- 갑옷은 기존 청회색 투구, 갈색 방패와 검을 참고한다. 검을 들어 예고하고 제자리에서 짧게 베고 복귀한다. 미리보기의 원은 근접 범위를 설명하기 위한 표시다.

원본 참고: `Assets/GameContent/Art/Pixel32/Monsters/Meadow/3/Walk_Meadow_3_0.png`, `Assets/GameContent/Art/Pixel32/Monsters/Dungeon/4/Walk_Dungeon_4_0.png`. 스타일은 `Docs/Art/Resource-style-guide.md` 기준이다.

생성 프롬프트는 기존 두 몬스터의 색·비율·장비·정면 사선 방향을 유지하고, 투명한 6열×2행 시트에 준비·공격·복귀 키프레임을 요구했다. 픽셀 계단과 제한된 색, 작은 불규칙 입자, 프레임 사이 여백을 우선했다. 원본을 그대로 분해한 리깅이 아닌 새 프레임 시안이므로 실제 적용 전 정렬·작은 크기의 가독성을 추가 확인해야 한다.

검증: 프레임 12개 구성과 두 공격 주기 전체 렌더 호출, 일시정지·재개·처음부터 제어를 JavaScript 스모크 검사로 확인했다. 로컬 브라우저 자동화가 설정에서 비활성화되어 실제 브라우저 화면 검증은 미실행이다.

재생 수정: 외부 PNG의 상대 경로 로딩에 의존하지 않도록 HTML에 PNG를 포함했다. 요청 전에 로드·오류 핸들러를 등록하고 캐시 로딩에서도 한 번만 시작한다. 화면에 로딩·재생·실패 상태를 표시한다. `node Tests/MonsterAttackPreviewRegression.cjs`로 비동기·캐시·실패 로딩, 실제 예약 콜백의 시간 진행과 제어를 검사한다.

`mushroom.gif`, `armor.gif`는 스크립트 없이 보는 몸동작 반복 GIF다. 원본 시트의 프레임을 순서대로 조립했고, 별도의 포자 이동과 범위 표시는 HTML에만 있다. 각 GIF에 서로 다른 디코딩 프레임이 6개 이상 있음을 검사했다.
