# 원본 몬스터의 공격 연출 시안

2026-11-04. `index.html`은 게임 원본 PNG 두 개를 바이트 그대로 포함한다. 새 그림을 생성하거나 원본 픽셀을 덮어쓰지 않는다. 기존 걷기 프레임 중 첫 프레임 한 장만 사용한다.

- 버섯: 약 0.6초 동안 가로 최대 13%, 세로 최대 10% 부풀고 발사 순간 작게 움찔한 뒤 복귀한다.
- 갑옷: 가로 최대 5% 늘고 세로 최대 7% 낮아지며 준비한다. 공격 순간 작은 떨림 후 복귀한다. 검·방패를 새로 그리거나 별도로 휘두르지 않는다.
- 몸동작은 `motion.js`의 변환만 사용한다. 이 시안에서는 인디케이터·포자·타격 이펙트를 제거했다. 실제 게임에서는 공격 판정 시스템이 별도로 인디케이터와 포자를 그린다.
- GIF는 몸동작만 보여준다. HTML과 같은 변환 곡선과 원본 PNG를 사용한다.
- 게임의 공격·피해 판정은 연결하지 않은 검토용이다.

`node Design/Monsters/AttackPreview-v2/build-preview.cjs`로 HTML·GIF를 다시 만든다. FFmpeg가 필요하다. `node Tests/MonsterOriginalMotionRegression.cjs`로 원본 이미지 일치, 변형 크기·움직임 상한, 복귀, 이미지 로딩과 애니메이션 진행을 검사한다. 실제 브라우저 화면 검증은 미실행이다.
