# 석재 내부 반복 경계 개선

내장 image_gen으로 중앙 전용의 낮은 대비 암반 질감을 생성했다. 기존 3×3 아틀라스의 중앙에는 모서리 밝음과 대각선 무늬가 있어 동일 타일 반복 시 격자가 강조됐다. GroundRule_1_1 타일의 스프라이트만 ProjectDM_DungeonInterior_Continuous_v1.png로 연결했다. 초원과 외곽 8칸의 연결 규칙은 유지한다.

## 프롬프트

Use case: stylized-concept. Create ONE perfectly seamless repeating top-down pixel-art dungeon bedrock FLOOR TEXTURE, not an atlas, not a tile illustration. Reference image is for palette and coarse pixel scale ONLY; ignore its stone border and central diagonal scratches. Fill the entire square edge to edge with one continuous flat dark desaturated blue-violet bedrock surface, average color approximately #30354f. No individual rectangular slab silhouette, NO beveled edges, NO bright corner triangles, NO border shadow, NO square outlines, NO grooves at canvas edges. All four edges must tile invisibly with matching color and detail distribution. Quiet uniform diffuse ambient lighting with no brighter top-left or darker bottom-right. 85 percent calm base color, just a FEW low-contrast asymmetrical organic mottled patches, chunky subtle pixel clusters approximately 48x48 logical pixel art enlarged cleanly. Shade differences only 5-10 RGB levels, maximum 5 stone colors. No dominant diagonal marks, no recurring arrow-shaped motif, no regular checkerboard, no brick joints, no separate rocks, no large cracks, no moss, no scattered props, no particles, no vignette, no gradients, no blur. Deliberate hand-placed broad pixel clusters with generous quiet negative space, flat low-contrast game floor that reads as one contiguous ground when repeated many times. Fully opaque square texture, no transparency, no text.
