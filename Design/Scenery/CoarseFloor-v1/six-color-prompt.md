# 6색 픽셀 타일 (적용)

내장 image_gen으로 생성 후 128×128로 nearest-neighbor 크기 변환하고 프롬프트의 고정 6색 팔레트에 최근접 RGB 색으로 정리했다. 따라서 그라데이션과 중간색이 없는 실제 128×128 PNG다. 프리뷰는 정수 배율 6배 확대다. 32×32씩 자른 4×4 내부 패턴으로 게임에 적용했다. 외곽도 32×32 크기와 같은 6색 팔레트로 정리했다. Unity에서 음수 좌표를 포함한 216칸의 참조·크기·패턴 주기와 렌더링을 확인했다. 개별 타일 회전은 제거했고, 초원의 배치는 유지했다. 적용 화면은 pixel-paving-applied.png다. 실제 메인 장면 플레이 리뷰는 수행하지 않았다.

## 생성 프롬프트

Use case: stylized-concept. Create a STRICT LOW-RES RETRO PIXEL GAME STONE FLOOR TILESET texture. It must look like authentic 16-bit console pixel tiles made in a pixel editor, not a painting with pixelated edges. 128x128 LOGICAL PIXELS total, intended to slice into sixteen 32x32 gameplay tiles. Render every logical pixel as a large uniform hard square. Only SIX EXACT FLAT SOLID COLORS TOTAL: #23283c grout, #30364e base, #3a425c midtone, #48516a small light patches, #2b3045 shadow, #535d73 very rare 1px chips. NO other colors, NO gradients within flat areas, NO anti-aliasing, NO blur, NO texture grain, NO soft lighting, NO broad diagonal soft shadow bands, NO painterly shading. Stone faces must each consist of one flat main color plus 2-3 tiny hard-edged stepped pixel clusters. A continuous medieval dungeon flagstone pavement with 8 staggered horizontal stone courses and irregular stone widths. Stones 10-30 logical pixels wide, rows 12-20 pixels high. Thin one-logical-pixel dark grout lines with occasionally uneven 1px chips, restrained contrast. Some long slabs, some short blocks; avoid uniform brick checkerboard. Entire sheet seamless horizontally and vertically, grout across opposite edges connects. No borders around 32x32 game cells; stone joints cross invisible cell boundaries. Flat top-down tile texture, filled edge to edge opaque, dark blue-gray palette. No moss, no props, no perimeter rock ring, no transparent background, no text, no grids or labels. Essential: bold CRISP CHUNKY PIXEL CLUSTERS and empty flat color areas exactly like a genuine old-school 32px dungeon floor tileset.
