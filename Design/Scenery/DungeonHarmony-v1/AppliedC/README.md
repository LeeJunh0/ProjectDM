# C안 적용 리소스

내장 image_gen으로 기존 리소스와 C 시안을 참조해 석재 6종·바닥·외곽 총 8종을 편집했다. 횃불 PNG/메타/불꽃 연출과 배치 레이아웃, 초원은 유지한다. 기존 석재의 캔버스 비율·메타·게임상 높이를 유지하기 위해 필요할 때 nearest-neighbor 크기 변환만 했다. 바닥은 1024×1024를 4×4(각 256px, PPU 256)로 나눠 월드 크기 1인 16개 타일로 연결한다. 기존 타일맵 배율 2에서 전체 8×8 월드 패턴이다. 횃불 원본과 변경 전 리소스는 Before, 생성 원본은 Generated에 보존한다.

## 적용 및 검증
C안 적용 완료. 실제 Unity 렌더는 unity-render.png. 석재 6종과 바닥·외곽 8종을 원래 참조 경로에 연결했다. 타일맵 4×4 내부 연결을 위해 바닥 메타만 16개 슬라이스로 바꿨으며 석재 메타와 피벗·배치·높이는 유지했다. 던전 외부 배경색을 차분한 청회색에 맞췄다. 횃불 PNG/메타, 장식 배치, 초원 파일의 원본 해시가 유지됨을 확인했다. Unity에서 전체 514개 장식 렌더, 석재 6종 명암/Point/투명도, 216칸 타일 연결 및 디버그 진입 검사 통과. 구조 회귀 검사 5,994개 통과. 렌더는 실제 리소스로 구성한 격리 장면이며 메인 장면 플레이 리뷰는 하지 않았다.

## 환경 선명도 보정 (2026-11-03)
두 스테이지의 환경 15종이 공통으로 64픽셀로 축소되어 윤곽이 흐려지는 문제를 재현했다. PNG 원본이나 색감은 바꾸지 않고 임포트 상한을 256으로 올리고 Point 필터·밉맵 없음·비압축을 유지했다. StageScenerySetup의 재연결 설정도 256으로 수정했다. 따라서 앞선 원본 해시 유지 검증 이후 PNG 메타의 해상도 상한은 의도적으로 변경되었다. 두 스테이지의 동일 구도 전후 렌더와 ScenerySharpnessRegression 15종 설정 검사 통과. 구조 회귀 5,994개 통과.
