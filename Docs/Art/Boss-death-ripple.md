# 중간보스와 보스 처치 파동

2026-10-20: 중간보스부터 구현합니다. 최종 보스 전투는 기존 도달 미리보기를 유지하고, 보스 계열의 공통 처치 경로에는 상자 확정 드랍과 파동을 연결합니다.

## 중간보스

`PrototypeBalance.json`의 설정을 사용합니다. 플레이 경과 60초마다 현재 해금된 가장 높은 몬스터 슬롯을 중간보스로 생성합니다. 선택한 초원/던전 스테이지의 기존 외형과 애니메이션을 그대로 사용합니다.

| 설정 | 기본값 | 동작 |
| --- | --- | --- |
| `miniBossInterval` | 60초 | 실제 런 경과 시간 기준, 최종 보스 도달 전까지 출현 |
| `miniBossScale` | 1.35 | 기존 크기와 투사체/접촉 판정 반경 배율 |
| `miniBossHealthMultiplier` | 5 | 기존 몬스터 HP 배율 |
| `miniBossRewardMultiplier` | 3 | 경험치·일반 재화·상자 내용물 배율 |

동시에 살아 있는 중간보스는 한 마리입니다. 일반 몬스터 리필 상한이 차 있어도 중간보스 한 마리는 추가 출현할 수 있습니다. 기존 개체가 살아 있으면 다음 출현을 기다리고, 다음 실제 출현 시각부터 간격을 다시 셉니다. 일시정지 동안 런 시계가 멈추며 재시작하면 출현 시각·몬스터의 보스 상태가 초기화됩니다.

중간보스/보스 계열은 처치 시 상자 **정확히 1개**를 확정 드랍합니다. 일반 상자 확률과 중복 추첨하지 않으며, 일반 몬스터는 기존 확률을 유지합니다. 보상은 실제 픽업 획득 시 지급합니다. 상자 기본 내용물은 기존 재화이며 별도 아이템 추첨은 추가하지 않습니다. 중간보스는 실제 처치 1회로 집계하고 최종 보스 도달/클리어 진행을 대신 기록하지 않습니다. 마나 드랍 확률과 회복량은 기존 규칙을 유지합니다.

## 공간 파동

처치 지점을 중심으로 얇은 원형 파동 두 겹이 차례로 퍼지며 사라집니다. 해당 띠 주변의 월드 배경이 살짝 굴절되고 옅은 청회색이 비칩니다. HUD에는 굴절을 적용하지 않습니다. 밝은 발광이나 화면 전체 플래시는 없습니다.

`Assets/Resources/ProjectDM/Effects/BossDeathRipple.asset`의 한글 Inspector에서 반경·지속 시간·색상·굴절 강도·동시 표시 상한을 조절합니다. 기본 반경은 중간보스 3.2, 보스 5 월드 단위, 수명 1.25초, 굴절 강도 2 화면 픽셀, 동시 상한 4개입니다.

현재 프로젝트의 Built-in 렌더 파이프라인용 `BossDeathRipple.shader`를 사용합니다. 활성 파동이 그려질 때 이름을 공유하는 GrabPass로 배경을 캡처하고, 각 파동은 같은 머티리얼과 메시를 재사용합니다. 파동이 없을 때는 렌더러가 비활성입니다. 실제 런의 스케일된 Tick/Reset 경로를 따르며 전투 난수를 소비하지 않습니다.

## 코드와 검증

- `EnemySystem`: 출현 간격·강화 수치·사망 1회 소유, 좁은 콜백으로 처치 연출 호출
- `PickupSystem.SpawnPrototypeLoot`: 보상 배율 및 상자 확정 드랍
- `BossDeathRippleVisuals` / `BossDeathRippleSettings`: 재사용 가능한 공간 파동과 설정
- `ProjectDMBossEffectsSetup`: 머티리얼/설정 설치 메뉴
- `MiniBossRegression`: 메모리 저장소에서 출현·배율·보상·중복 사망·풀 재사용·셰이더 렌더·정지·정리·상한 확인
- `PrototypePlaySmoke`: 실제 Main/Addressables에서 중간보스 처치 → 상자 + 파동 연결 확인
