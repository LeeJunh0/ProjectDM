# 데미지 숫자 외형

2026-10-20: 데드셀처럼 폭이 좁고 각진 숫자를 참고하되 현재 리소스의 부드러운 톤에 맞춥니다.

- 숫자 글꼴: VT323 Regular. 일반 UI와 분리된 숫자용 픽셀 글꼴이며 인위적인 Bold는 사용하지 않습니다. 전용 폰트 아틀라스는 Point 필터로 표시합니다.
- 일반 피해: 따뜻한 아이보리 `(0.96, 0.94, 0.86)`
- 치명타: 따뜻한 금색 `(1, 0.74, 0.26)`, 기존 1.4배 크기와 `!` 표식 유지
- 플레이어 피격: 기존 붉은색과 마이너스 표식 유지
- 외곽선: 회갈색 `(0.26, 0.24, 0.23, 0.8)`, 1080p 기준 1픽셀, 네 방향으로 얇게 표시
- 별도의 발광·장식·광택은 사용하지 않습니다.

## 속성별 색상

화염·번개·빙결은 같은 외형 설정 에셋에서 일반/치명타 색을 각각 조절합니다. 마법미사일은 위 아이보리/금색과 GameManager 설정을 그대로 사용합니다.

| 공격 | 일반 피해 | 치명타 |
| --- | --- | --- |
| 마법미사일 | 따뜻한 아이보리 | 금색 |
| 화염 | 주황·붉은색 `(0.96, 0.43, 0.22)` | 밝은 살구·주황 `(1, 0.78, 0.43)` |
| 번개 | 연보라 `(0.68, 0.65, 0.97)` | 밝은 보라 `(0.88, 0.82, 1)` |
| 빙결 | 청록빛 하늘색 `(0.43, 0.78, 0.91)` | 옅은 얼음색 `(0.76, 0.94, 1)` |

치명타는 속성 계열을 유지하면서 명도를 높이고, 기존 크기 1.4배와 `!` 표식으로 구별합니다. 플레이어가 받는 피해는 속성에 관계없이 기존 붉은색입니다. 숫자에 별도 발광을 추가하지 않습니다.

`SkillSystem.ApplyPersonalHit`가 각 직접/연쇄/화염 범위/빙결 공전 적중의 속성을 `EnemySystem`의 좁은 연출 콜백에 전달합니다. 지연된 화상 피해도 화염 속성을 명시하며 기존대로 치명타를 새로 판정하지 않습니다. 팝업은 생성될 때 속성을 보관하고, 풀 재사용 시 덮어써서 이전 캐릭터의 색이 섞이지 않게 합니다. 실제 피해·치명타 확률·마나·사망/보상 계산은 유지합니다.

`Assets/Resources/ProjectDM/UI/CombatDamageAppearance.asset`의 한글 Inspector에서 글꼴·외곽선 색·두께와 속성별 일반/치명타 색을 바꿉니다. 마법미사일/피격 색상과 숫자 크기·표시 시간·크기 변화·떠오름은 기존 GameManager 한글 Inspector를 사용합니다. 현재 Main 씬에 설정된 42 크기/2초 표시/크기 변화 등 모션 설정은 유지합니다.

`CombatDamageDisplay`의 기존 풀·상한·정지·화면 투영·표시 위치·피해 문자열을 유지하며 글꼴·외곽선·속성 색을 적용합니다. `GameSettings`와 GameManager의 기본 색 및 Main 씬의 일반/치명타 색을 같은 값으로 맞춥니다. 실제 데미지·치명타 판정·전투 난수는 변경하지 않습니다.

폰트 출처: [Google Fonts VT323](https://github.com/google/fonts/tree/main/ofl/vt323), [원저자 프로젝트](https://github.com/phoikoi/VT323). 원본 TTF를 수정하지 않고 사용하며 SIL Open Font License 1.1 전문을 TTF 옆 `OFL.txt`에 포함합니다.

`Project DM/Install Pixel Damage Appearance`는 설정의 폰트 연결을 설치합니다. `DamageAppearanceRegression`은 실제 폰트의 숫자·소수점·치명타·피격 표식 지원을 확인하고 `Logs/DamageAppearance-preview.png`에 글꼴·색상 샘플을 네이티브 TextMesh로 렌더합니다. 샘플은 같은 폰트/색/외곽선을 사용하는 외형 확인용이며, 실제 IMGUI의 화면 투영·동적 크기·모션을 캡처한 장면은 아닙니다.

검증 결과: 폰트/문자 지원·외곽선·샘플 렌더 통과, 기존 숫자 크기 연출 878개·시스템 구성 6,493개 검증 통과, 실제 Main 플레이 스모크 통과. Main 씬 변경은 일반/치명타 색상 두 항목뿐입니다.

속성색 후속 검증: 캐릭터 회귀 3,548개(실제 미사일·연쇄·화염 범위·빙결 공전 적중 속성과 강제 치명타·지연 화상 포함), 숫자 크기 878개·시스템 구성 6,493개 및 실제 Main 플레이 스모크 통과. 색상 해석·피격 색 우선·풀 재사용 초기화와 4종 일반/치명타 미리보기도 확인했습니다.
