# 성장 노드 아이콘

성장 노드에서 사용하는 그림은 게임의 드롭·몬스터·스킬 리소스를 참고해 **새로 그린 전용 아이콘**이다. 원본 게임 스프라이트를 노드에 그대로 표시하지 않는다. 마나의 푸른 소용돌이, 자석의 파란 몸체와 청록 보석·금색 띠, 등급별 화폐의 색과 금속 테두리, 풀 슬라임의 두 잎과 네모 눈, 던전 박쥐의 분홍 날개 등 실제 게임에서 알아볼 수 있는 특징을 유지한다.

## 스킬과 성장 속성의 조합

전용 성장 노드는 스킬 기본 아이콘 위에 성장 속성을 뜻하는 작은 보조 아이콘을 오른쪽 위에 겹쳐 그린다. 예를 들어 마력탄 위력·빠른 시전·추가 마력탄은 모두 마력탄 그림을 사용하지만 위력·속도·개수 보조 아이콘으로 구분한다. 작은 아이콘은 노드 확대·축소에 따라 함께 크기가 변한다.

| 보조 아이콘 | 용도 |
| --- | --- |
| 위력 / 속도 / 개수 | 피해량, 시전 속도, 투사체·대상 수 |
| 범위 / 넓이 / 지속시간 | 거리·반경, 크기·각도, 지속시간 |
| 회전 / 유도 / 관통 | 공전 속도·회전·재타격, 유도, 관통 |
| 분기 / 연결 | 분열·분기, 연쇄·연결·연쇄 파쇄 |
| 화상 / 냉기 / 해금 | 화상 효과, 냉기 효과, 추가 스킬 해금 |

빙결과 확률 보조 아이콘도 향후 사용을 위해 준비해 두었다. 현재 67개 전용 성장 모두 스킬 기본 아이콘과 속성 보조 아이콘을 갖는다.

## 시트와 적용

| 리소스 | 구성 |
| --- | --- |
| `OrganicSkills_v3.png` | 마력·화염·번개·빙결 스킬 기본 아이콘 시안 적용본 |
| `OrganicLightningOrb_v3.png` | 현재 게임에서 보라색인 전기 구체를 닮은 전용 아이콘 |
| `MatchedModifiers_v2.png` | 성장 속성 보조 아이콘 16종 |
| `MatchedStats_v2.png` | 공통 능력치 아이콘 16종 |
| `MatchedUtility_v2.png` | 드롭·기능성·공용 효과 아이콘 12종 |
| `MatchedDungeonPopulation_v2.png` | 던전 박쥐 기반 몬스터 생성 아이콘 4종 |

모두 `Assets/Resources/ProjectDM/UI/GrowthIcons/`에 있으며 Point·mipmap 없음·무압축으로 가져온다. `GrowthIconVariants`가 각 성장 ID에 맞는 조합을 선택한다. 초원과 던전에서는 몬스터 생성 계열에 각각 풀 슬라임·박쥐를 닮은 별도 그림을 사용한다. 구형 `health` ID는 최대 마나 아이콘으로 연결한다.

시트마다 아이콘 간 여백이 일정하지 않아 원본 이미지의 실제 경계를 기준으로 잘라 표시한다. 기본 아이콘은 작은 입자보다 주된 그림에 무게를 둔 불투명도 가중 중심을 노드 중심에 맞춘다. 이 중심 보정값은 `GrowthIconVariants`에 시트별 순서로 기록되어 있으므로 원본 그림이나 분할 영역을 변경하면 다시 측정해야 한다. 원본 PNG는 수정하지 않는다. 기존 `GrowthStats`, `GrowthUtility`, `GrowthSkills` 시트는 기존 생성 결과와 폴백 및 전투 이펙트를 위해 보관한다. 성장 전용 새 시트는 전투 이펙트의 스프라이트를 바꾸지 않는다.

이후 새 리소스의 공통 스타일과 선택한 프롬프트는 [리소스 스타일 기준](Resource-style-guide.md)에 기록한다. 이전 생성 프롬프트와 사용한 게임 리소스 참조는 `Design/GrowthIcons/generation-manifest.json`에 보관한다. [아이콘 조합 미리보기](../../Design/GrowthIcons/index.html)에서 기본 그림과 보조 아이콘을 함께 볼 수 있다.

격리 Unity 6000.3.18f1에서 67개 전용 성장의 기본·보조 그림, 공통 성장과 스테이지별 변형, 기존 전투 이펙트 연결을 검사했다.
