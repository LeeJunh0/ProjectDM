# 캐릭터별 성장 트리 색상

2026-10-22: 캐릭터 전용 성장 트리의 배경·노드·연결선·완료 표시·구매 단계 표시·선택/호버 강조·상세 패널·툴팁·지갑 패널을 캐릭터 색으로 나눕니다. 공통 성장 트리는 기존 금색을 유지합니다.

| 캐릭터 | 전용 성장 트리 색상 |
| --- | --- |
| 마법미사일 | 크림·옅은 금색 |
| 화염 | 주황·붉은색 |
| 번개 | 연보라 |
| 빙결 | 하늘색·청록 |

캐릭터 선택 버튼도 각 캐릭터 색을 띠며 선택된 버튼을 더 선명하게 표시합니다. 캐릭터 선택 즉시 **보고 있는 전용 트리**의 색이 바뀝니다. 전투 중인 캐릭터나 구매한 능력이 즉시 변경되는 것은 아니며 기존대로 다음 런부터 적용합니다.

`Assets/Resources/ProjectDM/UI/GrowthGraphTheme.asset`의 한글 Inspector에서 네 캐릭터의 강조색을 조절합니다. 화면의 각 요소는 기존 색의 명도와 알파를 유지하면서 캐릭터 강조색의 색상·채도로 바뀝니다. 잠김 상태는 어둡게, 완료/도달 가능 상태는 선명하게 유지합니다. 미노출 노드는 칸과 선을 모두 그리지 않습니다. 지갑의 재화 숫자와 공통 목표 경로는 기존 구분색을 유지하고 공용 런 이동 버튼도 기존 외형입니다.

2026-10-26: 중앙은 현재 선택 캐릭터의 속성색 액체를 담은 유리 포션 UI입니다. 병 안에서 마력 궤적·화염·분기 방전·눈꽃이 움직이고, 액체의 물결과 기포 및 유리 반사를 표시합니다. 공통 트리의 일반 노드는 기존 금색을 유지하며, 중앙 상징과 구매한 가지를 따라 중앙으로 흐르는 빛은 선택 캐릭터 강조색을 사용합니다. 둥근 병은 수평선 기준 35도로 기울고 도트 외곽·유리 반사 및 초록 줄기 장식을 사용합니다. 병목을 감싼 줄기 끝은 둥글게 말리고 몸통 아래에도 짧은 줄기가 감깁니다. 액체의 낮고 느린 물결과 마나 바에서 공유하는 내부 흐름을 사용합니다. 굽이치는 색 흐름과 빛의 띠로 움직임을 드러내고 중앙 속성 심볼을 함께 표시합니다. 액체 높이는 현재 트리의 구매 진행률에 맞추며, 전부 완료했을 때 병목까지 가득 채우고 해당 강조색의 더 넓고 밝은 후광과 유리 테두리 빛을 더합니다. 중앙 속성 심볼은 마력 문양·불꽃·분기 번개·큰 눈꽃으로 구분하며 잔물결보다 또렷하게 표시합니다. 심볼은 내용물과 별도로 그려 빈 병에서도 보이며 수면에 잘리지 않습니다. 포션 아래 이름은 숨기고 중앙 포션 전체를 기존 대비 1.5배 키웁니다. 줌을 줄여도 최소 크기를 유지합니다. 포션과 내부 효과는 `GrowthPotionRenderer`와 `GrowthPotion.shader`가 그리고, 외곽의 은은한 빛과 가지의 흐름은 `GrowthTreeEffects`가 그립니다. 게임 일시정지 중에도 움직이며 실제 구매 조건이나 저장 데이터는 바꾸지 않습니다.

노드 배치·크기·가격·구매·해금·줌·이동·저장 규칙은 그대로입니다. `Project DM/Install Character Growth Colors`는 설정 에셋을 최초 생성하며 기존 사용자 설정은 덮어쓰지 않습니다.

`GrowthGraphThemeRegression`은 실제 전용/공통 그래프를 구성해 선택 캐릭터 기준 색상, 공통 금색 유지, 숨김 상태, 활성 캐릭터·저장·전투 난수 불변을 확인합니다. 기존 `GrowthGraphQa`와 `CharacterRegression`으로 구매·패널/노드 배치·캐릭터 전용 그래프도 함께 확인합니다.

검증 결과: 테마 31개, 기존 성장 그래프 282,865개(구매 2,887회·배치 문제 0개), 캐릭터 3,548개, 시스템 구성 6,495개 검증 통과. 기존 구형 그래프 구성의 작은 화면 자동 맞춤도 정적 오버레이 목록과 같은 캐릭터 선택 영역을 예약하도록 한 줄 정리했습니다. 캐릭터가 있는 실제 게임의 예약 영역은 그대로입니다.

실제 Main 플레이 스모크도 통과했습니다.
