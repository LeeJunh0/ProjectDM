# 몬스터 4프레임 · 거친 도트 수정

이 문서는 32픽셀 변환 전의 제작 원본 기록입니다. 현재 게임에 연결된 최종 파일은 [실제 32×32 리소스](Native32-art.md)이며, 눈·얼굴·갓 유지 수정도 그 출력에 반영합니다.

2026-10-23 사용자 피드백에 따라 매끈해진 6프레임 시트를 교체합니다. PixelLab은 사용하지 않으며, 최초 승인한 초원·던전 2프레임 원본을 기준으로 내장 `image_gen`에서 4개의 실제 동작 포즈를 제작합니다. 큰 정사각 도트 덩어리, 거친 계단형 윤곽, 제한된 재질 명암을 유지합니다.

| 스테이지 | 파일 | 동작 |
| --- | --- | --- |
| 초원 | `Assets/GameContent/Art/Monsters/ProjectDM_Meadow_Walk_4Frame_Rough_v3.png` | 슬라임 압축·도약, 새싹 정령 보행·잎 흔들림, 고블린 보행·팔 흔들림, 버섯 보행, 멧돼지 달리기 |
| 던전 | `Assets/GameContent/Art/Monsters/ProjectDM_Dungeon_Walk_4Frame_Rough_v3.png` | 박쥐 날갯짓, 쥐 달리기, 사슬 유령 부유, 돌거미 다리 교차, 망령 갑옷 보행 |

시트당 4열×5행, 20프레임으로 총 40개 스프라이트를 사용합니다. 중간보스도 같은 4프레임을 사용합니다. 최종 보스 도달 미리보기는 기존 리소스를 유지합니다. 원래의 2프레임 PNG와 ID는 보존합니다.

실제 PNG 크기는 두 시트 모두 1122×1402px이며, 배치 셀은 여백 포함 약 280×280px입니다. Unity에서는 실제 그림의 경계를 기준으로 더 작은 사각형으로 슬라이싱합니다. 각 원본 픽셀은 RGBA를 가지지만, 24×24나 32×32 고정 격자에 직접 찍은 네이티브 저해상도 그림은 아닙니다. 생성 프롬프트의 24~32픽셀은 표현 밀도에 대한 지시이며 보이는 큰 도트 내부에도 미세한 색 변화가 있을 수 있습니다. Point 필터·96 PPU·무압축·밉맵 없음으로 임포트합니다.

재생 주기는 몬스터별로 유지하면서 4프레임으로 간격을 조정합니다. 프레임 시간의 나머지 보존, 큰 시간 간격의 따라잡기, 빙결 정지와 냉기 감속, 풀 재사용 초기화도 유지합니다. 임포터는 실제 투명 구간을 사용하고, 공통 세로 기준·수평 픽셀 질량 피벗·그림 크기 보정으로 프레임 전환 때 잘림과 튐을 방지합니다. 판정·체력·이동·보상·중간보스 배율은 변경하지 않습니다.

[생성 프롬프트](Monster-animation-prompts.json)와 [Unity 재생 미리보기](Monster-animation-preview.gif)를 함께 저장합니다. 미리보기 왼쪽은 초원, 오른쪽은 던전입니다. 임포트·회귀 진입점은 `ProjectDM.Editor.MonsterAnimationArtSetup.RunBatch`, 실제 Main 씬 검증은 `ProjectDM.Editor.PrototypePlaySmoke.RunBatch`입니다.

최종 임포트 검증에서 40포즈와 재생기 288개, 스테이지 194개, 과거 아트 240개, 스프라이트 참조 187개, 중간보스 28개, 캐릭터 마법 3,548개 검증이 통과했습니다. 실제 Main/Addressables 플레이에서 스테이지 반복 전환·전 몬스터 4프레임 루프·빙결과 해제 중 시간·냉기 감속·풀 재사용도 통과했습니다. 수동 장시간 플레이나 실행 파일 빌드는 수행하지 않았습니다.
