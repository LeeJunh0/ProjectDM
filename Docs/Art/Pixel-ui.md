# 픽셀 UI 프레임

2026-10-27. 승인한 `Design/UI/PixelUI_v1` 리소스 12종을 `Assets/Resources/ProjectDM/UI/PixelUI`에 연결한다.

`Assets/Scripts/Systems/UI/Common/PixelUiArt.cs`가 원본 PNG 안의 실제 프레임 영역과 모서리 분할을 관리한다. 원본 이미지는 자르지 않고 UV로 여백만 제외한다. 패널·버튼·카드는 아홉 영역으로 나누어 그리므로 가로·세로 표시 크기가 바뀌어도 모서리 장식과 테두리가 과하게 늘어나지 않는다. 텍스처는 Point, mipmap 없음, NPOT 크기 유지, Clamp, 무압축, alpha transparency로 가져온다.

| 리소스 | 적용 위치 |
| --- | --- |
| panel_result | 런 결과창 |
| panel_tooltip | 성장 상세·툴팁·보스 도달·디버그 패널 |
| button_primary / button_secondary | 시작·복귀·구매·성장 지도 등 동작 버튼 |
| card_bronze / card_silver / card_gold | 레벨업 선택지 카드 |
| mana_frame | 마나바·결과의 누적 처치 게이지 |
| growth_node | 성장 노드·목표 노드 |
| tab | 캐릭터·스테이지·성장 종류 선택 |
| currency_badge | 성장 지도 보유 재화 |
| divider | 결과창 구분선 |

등급 카드는 상단에 별도의 등급 칸을 두지 않는다. `RunUpgradePresentation.grade`의 원본 등급 ID로 금·은·동 프레임을 선택하며, 번역된 표시 문구에 의존하지 않는다. 기존 카드 하단의 등급 표시도 유지한다.

선택지 카드의 빛은 프레임 뒤에만 그리는 공유 64×64 테두리 마스크다. 등급 강조색으로 표시하고, 게임이 일시 정지되는 레벨업 화면에서도 `Time.unscaledTime`으로 3.8초마다 알파가 0.19–0.27 사이에서 부드럽게 변한다. hover 시 0.11을 더한다. 카드 중앙과 텍스트에는 빛 마스크를 씌우지 않는다. 카드 등장·회전·확대와 동일한 GUI 변환을 사용한다.

마나바는 어두운 바탕 → 기존 액체 렌더러 → 투명한 픽셀 프레임 순으로 그린다. 액체 흐름과 소모량·피격 흔들림·파란 화면 가장자리 연출은 유지한다. 성장 지도는 기존 속성색·노드 상태·다음 한 칸 공개·포션·중앙으로 향하는 흐름을 유지한다.

플레이 중 재화 HUD는 배경 박스 없이 우측 상단에서 기존 코인 아이콘과 보유 수량만 한 줄로 표시한다. 폭 600 미만에서는 경과 시간 아래 행에 배치한다. 성장 지도·디버그 버튼은 재화 HUD 아래에 위치한다. 획득 연출의 도착점 `RunHudView.CurrencyPickupTarget`은 코인 아이콘 중앙, `ManaPickupTarget`은 피격 흔들림을 반영한 기존 마나바 중앙이며, 둘 다 좌측 상단이 원점인 GUI 화면 좌표다.

필드 마나 드롭은 기본 배율 3에서 현재 카메라의 픽셀 밀도와 실제 불투명 그림 영역을 기준으로 비행 연출과 같은 화면 크기로 생성한다. 인스펙터 마나 배율은 이 크기에 비례해 조절된다. 자석 크기는 별도로 유지한다.

경험치는 화면 좌우 끝까지 이어지는 높이 30픽셀의 보라색 바로 표시하며 화면 바닥에 여백 없이 붙인다. 기존 마나 프레임을 사용하고 별도 레벨 패널 없이 바 내부 중앙에 밝은 `Lv.` 텍스트와 작은 그림자를 표시한다. 경험치 수치와 EXP 문구는 생략한다. 채워진 부분은 밝은 윗면과 작은 끝빛으로 구분한다. 경험치의 비행 도착점 `RunHudView.ExperiencePickupTarget`은 경험치 바 내부 중앙의 레벨 텍스트 중심이다. 도착 반짝임·수치 지연·0.28초 채움은 새 위치에서도 동일하게 적용한다.

재화·마나·경험치를 획득하면 실제 드롭의 스프라이트가 그 자리에서 즉시 해당 UI를 향해 날아간다. 작은 호·큰 호·완만한 S자 경로를 섞고, 출발 각도·굽힘 폭·가속 정도와 0.56–0.92초의 비행 시간을 개별적으로 달리한다. 경로는 화면 안에서 앞으로 진행하고 마지막에 UI로 모이며 출발 시 튀어 오르기·대기는 없다. 그림의 긴 변을 1080p 기준 38픽셀로 유지하다 마지막 12% 구간에서 투명해진다. 32픽셀 원본의 투명 여백은 `PickupSpriteBounds.json`에 기록한 알파 영역으로 제외한다. 원본 픽셀을 변경할 때는 이 측정값도 갱신한다. 궤적에는 약 0.024초마다 크기·밝기가 다른 금빛/푸른빛/보랏빛 픽셀 입자를 남기고, 입자는 0.34–0.50초간 반짝이다가 흩어진다. 입자 중심은 밝게 유지하고 일부 입자에 공용 16×16 광채 텍스처와 십자 반짝임을 더해, 작은 반투명 점으로만 보이지 않도록 한다. 도착 시 코인 아이콘은 살짝 커지고 마나·경험치 바는 은은하게 반짝인다. `PickupFlightPresentation`이 비행·입자·도착 반응만 관리하며 보상은 기존처럼 획득 즉시 반영된다. 화면의 재화 수량·마나 수치와 액체 채움·경험치 및 표시 레벨은 비행 중인 양을 제외하고 표시하며 각 비행이 도착한 뒤 0.28초 동안 SmoothStep으로 부드럽게 반영한다. 연속 획득은 각 채움이 겹쳐 진행되며 경험치가 레벨 경계를 넘으면 바를 채운 뒤 다음 레벨로 이어진다. 마나 소모와 피격은 즉시 표시하고, 화면 전환·결과창에서는 확정된 실제 값을 사용한다. 보이지 않는 위치나 누락된 그림 때문에 비행이 생성되지 않으면 표시도 즉시 갱신한다. 마나가 가득 차 실제 회복량이 0이면 회복 비행을 만들지 않는다. 레벨업 선택 중에도 이미 시작한 비행은 창 위에서 도착까지 진행하고, 성장 지도·화면 전환·런 종료·새 런에서는 남은 연출을 지운다. 드롭마다 별도 오브젝트를 생성하지 않고 재사용 목록과 기존 스프라이트로 표시하며, 동시 비행 개수를 제한하지 않는다. 경로의 변화는 별도 해시로 정해 드롭·강화 추첨의 난수에 영향을 주지 않는다.

런 종료 시 결과창은 페이드 없이 즉시 표시한다. 성장 지도로 이동하거나 다음 런을 시작할 때의 페이드는 유지한다.

검증: 격리 Unity 6000.3.18f1에서 컴파일 및 리소스 12종의 로딩·UV·모서리 영역·임포트 설정·등급 연결·빛 마스크 68개 검사 통과. 실제 게임 플레이의 최종 시각 확인은 사용자 플레이 리뷰에서 진행한다.

플레이 HUD의 좌측 하단에는 선택한 마법사 타입의 176×176 초상화를 표시한다. 초상화와 마나바 하단은 경험치바 바로 위에 여백 없이 맞추고, 초상화 오른쪽 12픽셀 간격으로 높이 32픽셀의 마나바를 배치한다. MP와 수치는 바 안에 표시하며 획득 연출도 이동한 마나바 중앙으로 도착한다. 초상화는 Design/Portraits/v1 시안을 Resources/ProjectDM/UI/Portraits에 타입별로 연결하고 Point 필터로 표시한다. 런 정보는 초상화 위로 옮겨 겹침을 피한다.
