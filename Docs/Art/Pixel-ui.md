# 픽셀 UI 프레임

2026-10-27. 승인한 `Design/UI/PixelUI_v1` 리소스 12종을 `Assets/Resources/ProjectDM/UI/PixelUI`에 연결한다.

`Assets/Scripts/Systems/UI/Common/PixelUiArt.cs`가 원본 PNG 안의 실제 프레임 영역과 모서리 분할을 관리한다. 원본 이미지는 자르지 않고 UV로 여백만 제외한다. 패널·버튼·카드는 아홉 영역으로 나누어 그리므로 가로·세로 표시 크기가 바뀌어도 모서리 장식과 테두리가 과하게 늘어나지 않는다. 텍스처는 Point, mipmap 없음, NPOT 크기 유지, Clamp, 무압축, alpha transparency로 가져온다.

| 리소스 | 적용 위치 |
| --- | --- |
| panel_result | 런 결과창 |
| panel_tooltip | 성장 상세·툴팁·보스 도달·디버그 패널 |
| button_primary / button_secondary | 시작·복귀·구매·성장 지도 등 동작 버튼 |
| card_bronze / card_silver / card_gold | 레벨업 선택지 카드 |
| mana_frame | 마나바·결과의 누적 처치 게이지 |
| growth_node | 성장 노드·목표 노드 |
| tab | 캐릭터·스테이지·성장 종류 선택 |
| currency_badge | 성장 지도 보유 재화 |
| divider | 결과창 구분선 |

등급 카드는 상단에 별도의 등급 칸을 두지 않는다. `RunUpgradePresentation.grade`의 원본 등급 ID로 금·은·동 프레임을 선택하며, 번역된 표시 문구에 의존하지 않는다. 기존 카드 하단의 등급 표시도 유지한다.

선택지 카드의 빛은 프레임 뒤에만 그리는 공유 64×64 테두리 마스크다. 등급 강조색으로 표시하고, 게임이 일시 정지되는 레벨업 화면에서도 `Time.unscaledTime`으로 3.8초마다 알파가 0.19–0.27 사이에서 부드럽게 변한다. hover 시 0.11을 더한다. 카드 중앙과 텍스트에는 빛 마스크를 씌우지 않는다. 카드 등장·회전·확대와 동일한 GUI 변환을 사용한다.

마나바는 어두운 바탕 → 기존 액체 렌더러 → 투명한 픽셀 프레임 순으로 그린다. 액체 흐름과 소모량·피격 흔들림·파란 화면 가장자리 연출은 유지한다. 성장 지도는 기존 속성색·노드 상태·다음 한 칸 공개·포션·중앙으로 향하는 흐름을 유지한다.

검증: 격리 Unity 6000.3.18f1에서 컴파일 및 리소스 12종의 로딩·UV·모서리 영역·임포트 설정·등급 연결·빛 마스크 68개 검사 통과. 실제 게임 플레이의 최종 시각 확인은 사용자 플레이 리뷰에서 진행한다.
