# 리소스 애니메이션 미리보기

Unity 메뉴 **Project DM → 리소스 애니메이션 미리보기**에서 엽니다. 플레이 모드에 진입할 필요가 없으며 씬 오브젝트와 리소스 설정을 수정하지 않습니다.

- 캐릭터·몬스터·보스·스킬·드랍템·기타 분류와 이름 검색
- 재생/일시정지, 이전/다음 프레임, 프레임 슬라이더와 하단 썸네일 선택
- 재생 속도 0.1~3배, 정수 픽셀 확대 1~12배, 격자·배경색·좌우 반전
- 캐릭터 걷기 4방향을 같은 시간과 배율로 나란히 비교
- 스프라이트 이름·해상도·전체 재생 시간 표시와 원본 설정 선택
- 프로젝트 변경 시 자동 갱신, 수동 새로고침 시 선택 유지

캐릭터는 실제 AnimationClip의 스프라이트 키와 시간, 몬스터는 StageDefinition의 프레임과 간격을 읽습니다. 현재 66개 묶음을 확인할 수 있습니다. 보스는 리소스의 두 프레임을 비교용 5fps로 재생하며, 현재 게임의 도달 미리보기는 첫 프레임만 표시합니다. 스킬의 단일 그림과 드랍 원본 프레임도 확인할 수 있으나, 코드로 적용하는 이동·회전·확대·부유·파티클은 이 창의 재생 대상에 포함하지 않습니다. 해당 구분은 창 안에도 표시합니다.

## 캐릭터 위쪽 크기 보정

위쪽 걷기 원본이 정면·측면보다 크게 그려져 있어 기존 32픽셀 공통 캔버스에 그대로 내보내면 방향 전환 시 몸이 커졌습니다. `Pixel32ArtSetup.Install()`은 캐릭터별 정면/위쪽 네 프레임의 원본 높이 중앙값으로 위쪽 축소 비율을 구하고, 위쪽 네 프레임 전체에 같은 비율을 적용합니다. 발 기준점과 공통 중심을 유지하며 Point 방식으로 샘플링합니다.

위쪽 캐릭터 16개 PNG만 변경합니다. 모든 출력은 여전히 32×32이며 PPU·GUID·캔버스·프레임 순서·재생 속도를 유지합니다. 정면/측면과 몬스터·스킬·드랍 출력은 바이트 단위로 동일합니다. 원본 시트와 플레이어 Transform/판정에는 변경이 없습니다. 다시 내보내도 보정 결과가 유지됩니다.

2026-10-26 에디터 정리로 일회성 검증 메뉴와 배치 검증 스크립트는 삭제했습니다. 미리보기 창과 32픽셀 내보내기는 계속 사용할 수 있습니다. 아래 검증 수치는 제작 당시 기록입니다.

미리보기 443개 검사(66개 묶음의 연결·타이밍·프레임 경계·루프·창 그리기·일시정지·이동·새로고침), 네이티브 32픽셀 1,560개, 캐릭터 아트/방향/실제 Animator 연결 230개 검증을 통과했습니다. 수정 전에는 위쪽 높이 검사가 실패함을 재현했고, 수정 후에는 네 캐릭터 모두 정면과 위쪽의 평균 높이·발 기준선 차이가 1픽셀 이내입니다.
