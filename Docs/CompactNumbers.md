# 재화·경험치 숫자 표기

재화·경험치·구매 비용은 **100만 미만까지 K를 쓰지 않고 숫자 전체와 쉼표로 표시**합니다. 사용자가 획득량을 크게 느끼도록 요청한 방향입니다. 100만부터 M → B → T로 단위를 전환합니다. 최대 소수 둘째 자리까지 표시하고 불필요한 0은 생략합니다. 실제 획득량/비용을 넘어 반올림하지 않도록 소수 셋째 자리부터 버립니다.

| 실제 수치 | UI 표기 | 한글 대응 |
| --- | --- | --- |
| 999 | 999 | 999 |
| 1,000 | 1,000 | 1천 |
| 12,500 | 12,500 | 1만 2,500 |
| 999,999 | 999,999 | 99만 9,999 |
| 1,000,000 | 1M | 100만 |
| 1,000,000,000 | 1B | 10억 |
| 1,000,000,000,000 | 1T | 1조 |

`CompactNumber`를 HUD의 현재/요구 경험치·획득/보유 재화, 성장 지도의 지갑·구매 버튼·비용 설명, 결과창의 획득 재화 카운트업에 적용합니다. 결과창은 단위가 바뀌는 도중에도 숫자가 잘리거나 아이콘 위치가 흔들리지 않도록 중간 표기의 최대 폭을 확보합니다.

표시 전용 변경입니다. 실제 보상·랜덤 범위·가격·경험치 요구량·구매 판정·저장 값과 저장 상한은 그대로입니다. 재화는 여전히 int 상한(2,147,483,647, UI 2.14B)이며 T 지원은 표시 함수의 지원 범위입니다. 수치 확대와 범위 랜덤 보상은 아직 제안 단계입니다. 체력·마나·공격력·처치 수·확률 표기는 기존 규칙을 유지합니다.

`Tests/CompactNumberRegression.ps1`에서 K 생략·쉼표 표시·M/B/T 경계, 소수 처리, 상한, ko-KR/en-US/de-DE 환경의 동일 표기를 검증합니다.

2026-10-20: 숫자 표기 66개, 시스템 구성 6,491개 검증과 결과창 카운트업 회귀 검증, 실제 Main 플레이 스모크를 통과했습니다.

같은 날 K 생략 요청 반영: `1,000`~`999,999` 전체 숫자 표시와 M 전환을 포함한 숫자 표기 69개 및 결과창 카운트업 검증 통과.
