# 아이템 획득 범위 확인 및 조절

Main 씬의 **Player Spawn Point**를 선택하면 노란 원과 오른쪽 노란 핸들이 나타난다. 인스펙터의 **직접 획득 반경**을 바꾸거나 씬 뷰에서 핸들을 좌우로 끌면 실제 아이템 접촉 획득 반경이 바뀐다. 현재 Main 씬의 설정값은 0.55 월드 유닛이다. 씬 뷰의 Gizmos 표시가 켜져 있어야 한다.

이 반경은 아이템을 끌어오는 범위와 별개다. 성장 전에는 끌어오기 범위가 직접 획득 반경과 같아 추가 끌어당김이 없으며, 성장할 때마다 직접 획득 반경에 성장분을 더한 범위에서 아이템을 끌어온다. 편집 중 **끌어오기 추가 반경 미리보기**에 숫자를 입력하면 직접 획득 반경에 더한 크기를 파란 원으로 확인할 수 있다. 이 미리보기는 실제 성장이나 게임 수치를 수정하지 않는다.

플레이 중에는 두 원이 플레이어를 따라간다. 파란 원은 현재 런의 실제 끌어오기 반경을 표시하며, 성장값이 0이면 노란 원과 같으므로 별도로 그리지 않는다. 플레이 중 인스펙터에서 직접 획득 반경을 바꾸면 즉시 반영되지만, Unity의 일반적인 Play 모드 변경과 마찬가지로 종료하면 저장되지 않는다.
