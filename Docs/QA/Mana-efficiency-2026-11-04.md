# 마나 효율 성장

공통 성장의 최대 마나 마지막 노드 다음에 `manaEfficiency_1`~`manaEfficiency_5`를 추가했다. 각 노드는 한 번만 구매하며 공격 마나 소모를 10%p씩 줄인다. 다섯 노드 완료 시 50% 감소한다. JSON 기본 그래프·화면용 `GrowthTrees.asset`·`Design/GrowthTree.xlsx`를 함께 갱신했다. 기존 마나 회복 아이콘을 재사용한다.

다음 런 시작 시 `RunMana.EfficientCost`가 캐릭터 기본 마나 소모량에 `1 - 효율`을 곱한다. 기본 비용 1이면 0.9, 0.8, 0.7, 0.6, 0.5 MP가 된다. 최대 마나·마나 회복·피격으로 잃는 마나는 변경하지 않는다. 보조 스킬은 현재 별도 마나 소모가 없으므로 추가 비용을 도입하지 않는다. 잘못된 초과 효율도 50%를 넘지 않도록 제한한다.

새 성장 ID가 없는 저장은 0%로 시작하며 기존 구매를 변환하거나 초기화하지 않는다. 런 도중 구매해도 활성 성장 스냅샷은 유지한다.

검증: `Tests/ManaEfficiencyRegression.cs`는 캐릭터 4종의 소비 감소와 피격 피해 유지, 다음 런 적용, 단일 구매 노드 5개·합계 50%, 그래프 구매 가능 여부·숨김·좌표 중복, 저장 직렬화, 엑셀 왕복을 검사한다. 기존 성장·가격·구조 회귀 검사도 실행한다. 수동 플레이와 효율 도입 후의 전체 성장 소요 시간 재측정은 미실행이다.
