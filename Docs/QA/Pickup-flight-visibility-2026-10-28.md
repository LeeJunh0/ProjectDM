# 획득 비행 크기와 궤적 가시성 확인

2026-10-28. 사용자 피드백에 따라 비행 그림의 긴 변을 1080p 기준 64픽셀에서 이전 44픽셀로 복원했다. 비행 중 크기는 유지하고 도착 직전 투명해지는 동작은 유지한다.

## 원인과 변경

`PickupFlightPresentation`의 입자 생성과 `RunHudView.DrawPickupFlights` 연결은 정상이다. 기존 궤적은 광채 없이 3–4픽셀 반투명 점만 그렸으며, 수명 중간에는 불투명도가 약 4–21%까지 낮아졌다. 비행 물체에 일부 점이 가려지는 것까지 겹쳐 빛의 잔상으로 읽히기 어려웠다.

입자에 밝은 중심점을 두고 일부 입자에 공용 16×16 주변 광채를 추가했다. 크기·밝기 차이와 십자 반짝임을 유지하며, 수명은 0.30–0.46초로 늘렸다. 중간 수명에도 중심 불투명도가 30% 이상 유지되고 마지막에는 완전히 사라진다. 재화·마나·경험치, 경로 다양성, 보상 처리에는 변경이 없다.

## 실제 렌더 확인

격리된 Unity 6000.3.18f1 재현 장면에서 실제 게임의 코인·마나·경험치 스프라이트 18개를 `PickupFlightPresentation.Draw`로 그렸다. 1920×1080 화면의 동일 비행 시점을 캡처하고, 입자만 제거한 같은 화면과 비교했다. 실제 메인 장면 전체를 플레이한 리뷰는 아니다.

- [변경 전](Pickup-flight-trail-before-2026-10-28.png): 입자로 인해 RGB 채널 하나라도 50/255 이상 밝아진 픽셀 285개.
- [변경 후](Pickup-flight-trail-after-2026-10-28.png): 같은 기준 3,094개. 궤적에 남는 색별 광채를 직접 확인했다.

Unity 컴파일 및 `PickupFlightRegression` 4,697개 검사 통과. 이 회귀 검사에는 중간 수명의 입자 밝기, 완전 소멸, 44픽셀 크기 복원, 곡선 진행, 300개 동시 비행, 획득 중복 방지, 일시 정지와 결과 전환 검사가 포함된다.
