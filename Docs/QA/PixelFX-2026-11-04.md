# PixelFX 스킬·입자 개선 검증

기본 4종·고유 8종 및 공통 명중·유성 충돌·획득 반짝임을 pixelfx로 작성했다. 최종 결과는 15클립·183프레임·24fps, 1200×1600 텍스처 1장이다. 소스·재생성·시각 기준은 `Design/Skills/PixelFX-v1/README.md`에 정리했다.

검토는 기존 pixelfx 4종 렌더 → 초기 시안 → 잔광·불꽃 끝 수정 → 게임 배경 비교 → 광선 중심·부채꼴 줄기 보강 → 실제 Unity 초원·던전 렌더 순서로 진행했다. `Design/Skills/PixelFX-v1/index.html`은 이미지가 포함된 단일 파일 미리보기이며, GIF도 별도로 제공한다.

## 확인 결과

- pixelfx `tools/check.mjs projectdm`: 15개 통과, 실패·경고 없음. 시드 재현성·영역 밖 그리기·루프 연결·단발 종료 등을 검사한다.
- `Tests/PixelFxRegression.cs`: 240개 검사 통과. 클립·UV·Point/비압축 임포트, 애니메이션 진행·종료·일시정지, 게임 난수 불변, 스킬 진입점, 공전 조각, 2,000개 효과 유지와 단일 텍스처 배치 검증.
- `Tests/PixelFxRuntimeRegression.cs`: 실제 Main 장면의 기존 Addressables 부팅 후 초원·던전에 8개 스킬을 함께 렌더했다. 실제 기본 마력탄 생성 경로와 이동 중 프레임 교체도 검사했다. 샌드박스에서 실행해 사용자 저장은 변경하지 않았다.
- 장면 종료 시 배치 루트가 먼저 파괴되면 소유 머티리얼을 읽지 못하던 문제를 발견했다. `SpriteQuadBatch`가 머티리얼을 직접 보관해 파괴 순서와 관계없이 해제하도록 수정하고 회귀 검사를 추가했다.
- `Tests/PixelFxPreviewRegression.cjs`: 프리뷰 15클립·예약 프레임 진행·초원/던전 전환·일시정지·이미지 내장·런타임 PNG/JSON 동일성 검사.
- 기존 성장·구조·데미지 연출 검사도 통과했다. 획득 연출은 별도 회귀 검사로 확인한다.

## 직접 조절 편집기와 최종 수정

`Project DM → 픽셀 이펙트 편집기`에서 15개 효과를 재생·일시정지·프레임 확인하며 수정할 수 있다. 수치·색은 `tuning.json`에 저장하고 ‘게임에 적용’으로 전체 시트를 내보낸다. 미리보기는 비동기로 생성하며 프레임 밖으로 나가는 픽셀이 있으면 적용 전에 막는다.

- `Tests/PixelFxEditorRegression.cs`: 격리 Unity에서 창 GUI, 15개 설정, 속도·색 변경 후 자동 재생성, 설정 저장, 전체 게임 리소스 적용과 재임포트까지 통과했다.
- `Tests/PixelFxTuningRegression.mjs`: 기본 15개 렌더, 승인된 11개 효과의 픽셀 동일성, 파라미터 변경·미리보기 브리지·잘못된 입력 거부·프레임 잘림 검사를 수행한다.
- 사용자 피드백에 따라 마력탄의 긴 꼬리를 짧은 직선 잔광으로, 화염 부채꼴의 긴 줄기를 전방으로 퍼지는 불꽃 덩어리로 교체했다. 유성 충돌 파편은 11→15개, 빙결 폭풍의 큰 별은 바깥쪽으로 이동했다.
- 최종 리소스로 pixelfx 검사 15개(경고 없음), Unity 240개 회귀 검사, 실제 Main 부팅 후 초원·던전 장면 렌더, 브라우저 프리뷰 회귀 검사를 다시 통과했다.

피해·판정·마나·충전 속도·드랍 난수를 수정하지 않았다. 가시 개수를 줄이거나 성능을 위해 이펙트를 생략하지 않았다. 배치 개수 검사는 FPS 측정이 아니며, 다수 몬스터가 있는 실제 플레이의 프레임 성능과 장시간 플레이 가독성은 아직 수동 확인하지 않았다. 스킬 이펙트를 사용한 실제 Unity 렌더는 `Design/Skills/PixelFX-v1/unity-meadow.png`, `unity-dungeon.png`다.
