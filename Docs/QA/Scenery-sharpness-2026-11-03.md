# 환경 리소스 선명도 보정

## 원인

초원과 던전 환경 15종의 큰 원본 PNG가 임포트 시 긴 변 64픽셀로 축소됐다. Point 샘플링은 이미 켜져 있었지만 축소 과정에서 섞인 픽셀을 그대로 확대해 나무와 기둥의 윤곽이 흐려졌다. 스테이지 장식 연결 툴도 매번 상한을 64로 지정했다.

## 변경

- 환경 PNG 메타 15개의 상한을 256으로 조정했다. PNG 그림, GUID, 피벗, PPU, 레이아웃, 세계 크기는 변경하지 않았다.
- Point 필터, 밉맵 없음, 기본 비압축 설정은 유지했다.
- StageScenerySetup의 이후 임포트도 256을 사용한다.
- 횃불은 그림·불꽃·색은 유지하고 임포트 해상도만 같은 규칙을 적용했다.

## 검증

ScenerySharpnessRegression은 기존 설정에서 `Dungeon_Bricks.png imported=64x64 cap=64`로 실패했다. 변경 후 15종의 실제 임포트 크기·Point·밉맵·압축 검사와 두 스테이지의 전체 장식 개수 유지 검사를 통과했다. 동일한 구도의 Unity 렌더에서 윤곽 개선을 확인했다. 구조 회귀 검사 5,994개 통과. 실제 메인 장면 플레이 리뷰는 미실행.
