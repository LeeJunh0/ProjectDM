# 유물 제련

런 결과창의 **귀환 작업실 · 연금 가마** 버튼에서만 들어간다. 런당 참가비 결제는 한 번이며, 참가비는 해당 런의 실제 획득 금화 전액이다. 이미 지급한 금화에서 차감하고 결과창에서 다시 지급하지 않는다.

## 배경과 동작

원정에서 돌아온 마법사가 자신의 작업실에 있는 낡은 연금 가마를 사용한다. 원정 금화에 남은 마력을 추출해 영구 유물의 재료인 조각으로 굳힌다. 금화는 추출하며 녹아 없어지고, 더 응축할수록 조각은 커지지만 불안정해져 실패하면 연기로 흩어진다. 이미 꺼낸 조각과 재사용하는 가마는 파괴되지 않는다.

작업실은 테두리 패널 없이 화면 전체를 사용한다. 중앙에는 크게 확대한 가마를 두되, 3배 확대안에서 가로 15%·세로 30%를 줄이고 아래로 옮겨 금화 투입과 조각·입자 연출에 필요한 상단 여백을 확보하고, 작업대는 화면 하단으로 이어진다. 가마 입구·몸통과 선택 버튼이 겹치지 않도록 위치를 맞춘다. 아래에는 나무 바닥을 그린다. 양옆 설명·제목·조건 문구는 표시하지 않는다. 우측 상단에는 금화·조각 아이콘과 수량만, 우측 하단에는 선택 버튼만 둔다. 참가비와 성공 확률은 버튼 안에 짧게 표시하며 참가할 수 없을 때도 버튼 문구로 이유를 나타낸다. 화면 비율에 맞춰 1920×1080 기준 구성을 축소해 모든 조작부가 화면 안에 남도록 한다.

첫 동작은 **금화 넣기**, 성공 후 선택지는 **조각 꺼내기 / 더 응축하기**다. 추가 응축에는 금화 투입 연출도 추가 차감도 없다. 최고 수입의 80%는 세계관 설명에 끼워 넣지 않고 별도의 참가 기준으로 표시한다.

`RelicForgeMotion`이 1.4초 동안 가마의 동작을 그린다. 0.72초에 결과가 드러나고 그전에는 보관함 숫자도 앞서 바뀌지 않는다. 동작 중 입력은 잠기고, TAB으로 작업대의 선택을 건너뛸 수 없다. 판정과 금화·조각 저장은 기존 제련 로직이 즉시 처리한다.

첫 투입에는 실제 참가비에 따라 금화가 더 많이 떨어진다. 표시 개수는 `min(참가비, clamp(ceil(8 × ln(1 + 참가비)), 1, 128))`로 압축한다. 예를 들어 10금화는 10닢, 1,000금화는 56닢, 100,000금화는 93닢으로 표현하며 결제 금액은 그대로다. 금화마다 낙하 위치·회전이 조금씩 다르고, 약 0.245초에 걸쳐 촘촘한 줄기로 출발해 0.18초 낙하 후 0.20초 동안 표면에서 겹치고 납작해지며 사라진다. 녹는 자리에 금빛 파문과 작은 입자가 남는다. 내용물과 응축 광원은 금색을 유지한다.

금화는 고정된 시트에 굽지 않고 가마 전용 `forge-coin-v1.png`를 사용해 런타임에 그린다. 추가 응축에는 표시 금화가 0개다.

`Assets/Resources/ProjectDM/UI/RelicForge/forge-effects.png`와 JSON은 대기·첫 추출 성공/실패·추가 응축 성공/실패, 총 5클립 164프레임의 2D·Point·비압축 시트다. 가마·작업대는 대기 레이어를 계속 그려 연출 종료 때 사라지지 않는다. 성공 후 미확정 조각은 가마 위에 남아 꺼낼 때까지 유지한다.

## 규칙

- 모든 캐릭터가 공유하는 최고 런 수입을 저장한다. 이번 런도 최고 기록 갱신에 포함한다.
- 참가비가 `ceil(최고 기록 × 0.8)` 이상이고 보유 금화로 결제할 수 있어야 한다. 수입이 0이면 참가할 수 없다.
- 각 도전은 독립적인 50%다. 행운과 전투·드랍 난수에 영향을 받지 않는다.
- 최대 3회. 연속 성공 시 미확정 보상은 총 **1 → 2 → 5개**다. 누적 합계 8개가 아니다. 세 번째 성공은 자동 확정한다.
- 첫 도전에서만 금화를 차감하며 성공해도 환급하지 않는다. 추가 도전은 추가 금화 없이 미확정 조각을 건다.
- 확정 받기는 조각을 영구 저장하고 해당 런의 제련을 끝낸다. 실패하면 이번 참가비와 미확정 조각을 잃는다. 기존 조각·성장노드는 유지한다.
- 이미 확보한 조각, 최고 기록, 금화와 미확정 보상을 기존 세이브에 저장한다. 도중에 종료했다면 저장된 성공 보상은 다음 초기화에서 한 번만 확정하며 참가비를 환급하지 않는다. 실험 모드는 실제 저장을 변경하지 않는다.

기존 세이브에는 과거 최고 런 수입이 없으므로 적용 이후 종료한 런부터 기록한다. 이번 범위는 제련과 조각 획득·보관까지이며, 유물 장착·강화 효과는 포함하지 않는다.

## 검증

`Tests/RelicForgeRegression.cs`는 80% 경계·올림·오버플로, 고정 50% 판정, 1/2/5 지급, 실패 손실, 중복 결제·참가·수령 방지, 실제 EndRun 연결, 저장·재접속 복구와 실험 모드 격리를 검사한다.

`Tests/RelicForgeRuntimeSmoke.cs`는 격리 프로젝트의 실제 Main 장면을 부팅하고 결과창 → 제련 → 결제 → 성장지도 진입 차단을 검증한다. 사용자 저장은 변경하지 않는다.

금액별 투입량·용해 시점까지 포함한 경제·표시 시점·중복 입력·2D/Point 임포트 검사 426개와 실제 Main의 첫 추출 성공 → 추가 금화 없이 재응축 실패 흐름을 통과했다. `Tests/RelicForgePreviewRegression.mjs`에서 이미지 로딩·재생·일시정지·프레임 이동, 동일한 응축 전반부와 다른 성공/실패 후반부, 금액별 투입량과 추가 응축의 금화 투입 생략을 확인했다. pixelfx 5클립 검사도 경고 없이 통과했다.
