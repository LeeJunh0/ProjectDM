# 스킬 공격 이펙트

승인받은 이미지 3개를 원본 그대로 복사해 실제 공격 연출에 연결했습니다. 카드/성장 그래프 아이콘과 기본 공격 투사체는 기존 리소스를 유지합니다.

## 리소스와 설정

- `Assets/GameContent/Art/Skills/ProjectDM_ChainLightning_v1.png`: 파랑·청록 연쇄 번개.
- `Assets/GameContent/Art/Skills/ProjectDM_Splash_v1.png`: 청록 원형 스플래쉬. 운석의 바닥 예고/충돌에도 형태를 재사용합니다.
- `Assets/GameContent/Art/Skills/ProjectDM_Meteor_v1.png`: 주황 불꽃 운석.
- `Assets/Resources/ProjectDM/Skills/SkillVisuals.asset`: 스프라이트 참조와 연출 설정. 인스펙터의 항목 이름은 한글입니다.

원본은 투명 PNG이며 임포트는 Single Sprite / Full Rect / Point / 최대 512픽셀 / 밉맵·읽기 비활성 / 무압축입니다. 승인 원본 픽셀은 별도로 편집하지 않았습니다. 셋 모두 `Resources` 설정 에셋의 직접 참조이므로 빌드에 포함되며, 로딩 후 같은 설정을 매 런 `SkillSystem.Reset`에서 전달합니다.

`SkillImpactTint.shader/.mat`는 스플래쉬 이미지의 밝기·알파를 유지하면서 주황색으로 변환합니다. 청록 RGB에 주황색을 곱해서 녹색으로 변하는 문제를 피하며 이미지 파일을 변경하지 않습니다.

## 동작과 조절 항목

- 번개: 이미지의 시작/끝 좌표를 각 적 위치에 정렬하고 짧게 점멸·페이드합니다. 표시 시간·투명도와 이미지 내 양끝 좌표를 조절할 수 있습니다.
- 스플래쉬: 타격 지점에서 빠르게 퍼졌다가 페이드합니다. 표시 시간·투명도·처음 크기·이미지 안 원형 영역 지름 비율을 조절할 수 있습니다.
- 운석: 바닥에 옅은 주황 예고를 두고 운석 머리를 가속 낙하시킵니다. 스킬 테이블의 원래 `delay`에 도달하면 충돌 연출로 전환합니다. 낙하 높이·너비·회전·이미지 내 타격점·예고/충돌 투명도·충돌 표시 시간/색상을 조절할 수 있습니다.
- 성능: 기본 최대 128개 동시 스프라이트. 풀링 재사용 시 색상·회전·크기·머티리얼을 초기화합니다. 상한 때문에 연출을 생략해도 전투 계산은 계속됩니다.

피해·발동 확률·대상 수·범위·운석 지연과 저장 데이터는 변경하지 않았습니다. 연출에는 전투용 `UnityEngine.Random`을 쓰지 않으며 정지 중에는 시간도 흐르지 않습니다. 원형 이펙트의 확산은 시각 연출이고 실제 범위 피해는 기존 타격 시점에 적용합니다. 설정/새 리소스가 없는 옛 테스트는 기존 bolt/gem 임시 연출을 유지합니다.

## 검증

`ProjectDM.Editor.SkillVisualRegression.RunBatch`는 임포트/리소스 참조, 번개 양끝 정렬, 스플래쉬 확산/정지, 운석 머리의 낙하/도달 시간, 주황 머티리얼, 풀 재사용/상한, 전투 난수 불변을 검증합니다. 그래픽 장치가 있으면 실제 셰이더 패스를 컴파일하고 렌더 결과의 청록/주황 색상도 검사합니다. `Logs/SkillVisuals-preview.png`는 격리 카메라로 렌더한 세 스킬 예시이며 실제 인게임 스크린샷은 아닙니다.

기존 `PrototypeRegression`과 `PrototypePlaySmoke`도 실행합니다. 원본 프로젝트의 열려 있는 씬과 실제 플레이어 저장 데이터는 변경하지 않습니다.
