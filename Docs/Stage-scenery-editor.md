# 스테이지 장식 배치

Unity 메뉴 **Project DM → 스테이지 장식 배치**에서 연다. 초원에는 풀·들꽃·이끼 낀 돌·관목과 네 종류의 나무, 석재 던전에는 벽돌·석재 잔해·횃불과 네 종류의 부서진 기둥이 기본 배치되어 있다. 큰 장식은 시작 지점 주변을 비우고 스테이지 곳곳에 드문드문 배치한다.

## 직접 배치하기

1. Main 씬을 열고 툴에서 초원 또는 석재 던전을 선택한다. 씬 뷰에는 선택한 스테이지의 바닥과 장식이 임시로 표시된다.
2. 팔레트 그림을 누르면 배치 편집과 붓 모드가 켜진다. 씬 뷰에서 좌클릭하거나 드래그하여 놓는다.
3. 붓 크기·회전·좌우 반전·드래그 간격을 조절할 수 있다. 격자 간격을 0으로 설정하면 자유 배치한다.
4. Shift를 누른 채 클릭·드래그하거나 지우개 모드로 지운다.
5. 선택 모드에서 장식을 클릭하면 이동 핸들과 선택 크기·회전·반전 설정을 사용할 수 있다. Delete 또는 선택 삭제 버튼으로 지운다.

단축키는 B: 붓, E: 지우개, V: 선택, Escape: 편집 끄기이다. Alt를 누르면 씬 이동 조작을 유지한다. Ctrl+Z로 붓질·삭제·이동을 되돌린다. 붓질이 끝나면 자동 저장하며 **배치 저장** 버튼도 제공한다. **기본 배치로 교체**와 **전체 배치 지우기**도 되돌릴 수 있다.

## 저장 위치와 동작

- 초원: `Assets/Resources/ProjectDM/Stages/MeadowScenery.asset`
- 던전: `Assets/Resources/ProjectDM/Stages/DungeonScenery.asset`
- 장식 원본: `Assets/GameContent/Art/Scenery/`
- 생성 도구·프롬프트·원본 경로: `Design/Scenery/generation-manifest.json`

각 `StageDefinition`의 **지형 장식 배치**가 배치 에셋을 참조한다. 다음 런을 시작할 때 선택한 스테이지의 저장된 위치를 불러온다. 매번 무작위로 다시 생성하지 않는다. 기준 필드 크기는 100×100이며 필드 크기를 바꾸면 위치 비율을 맞추고 장식 자체의 크기는 유지한다.

장식은 이동을 막지 않으며 캐릭터와 몬스터 앞에 표시한다. 캐릭터 그림의 중심이 장식의 실제 불투명한 부분에 닿으면 해당 장식만 도트 디더링으로 서서히 옅어지고, 벗어나면 다시 선명해진다. 투명 여백이나 흐린 가장자리는 포함하지 않는다. 몬스터·보스와 드롭 아이템은 장식 뒤에 표시하고 디더링을 유발하지 않는다. 스킬 이펙트는 장식 위에 표시한다. 시작 지점 주변은 기본 배치에서 비워 둔다. 횃불은 불빛과 불티가 움직이며 게임 일시 정지와 함께 멈춘다.

편집 미리보기는 씬 파일에 저장되지 않으며 창을 닫거나 Play 모드로 들어가면 제거된다. 툴의 스테이지 선택은 실제 게임의 시작 스테이지 설정을 바꾸지 않는다.

## 장식 추가 및 성능

배치 에셋의 팔레트에 고유 ID·이름·스프라이트·높이를 추가하면 툴에 나타난다. 기존 ID를 바꾸면 해당 ID의 배치도 함께 수정해야 한다. `Import Stage Scenery` 메뉴는 기본 리소스와 빠진 배치 에셋을 연결하며 이미 저장된 수동 배치를 덮어쓰지 않는다.

장식 PNG는 Point·mipmap 없음·무압축·최대 64px·Read/Write 활성화로 가져온다. 런타임에는 텍스처별 메시로 묶고 배치 기하를 한 번만 만든다. 텍스처의 알파 마스크를 캐시해 캐릭터와 실제 그림이 겹치는지 확인하고 디더링 단계가 바뀐 텍스처의 정점 색상만 갱신한다. 장식 수만큼 GameObject를 만들거나 보이는 수를 줄이지 않는다.

## 검증

격리 Unity 6000.3.18f1에서 컴파일, 스테이지 전환, 배치 전체 렌더링, 재시작 시 중복 방지, 필드 좌표 변환, 전투 난수 상태 보존, 붓·지우개·Undo/Redo·에셋 저장·편집 미리보기의 씬 저장 제외와 정리까지 101개 검사를 통과했다. 초원 828개·던전 478개의 기본 배치를 실제 카메라로 렌더링해 `Design/Scenery/preview-*.png`에 남겼다. 전체 게임의 플레이 리뷰와는 별도의 장식·도구 검사다.
